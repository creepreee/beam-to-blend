# Contributing

## How to work on this project

1. Keep changes small and focused.
2. Update docs when behavior changes.
3. Add tests or validation scripts when possible.
4. Avoid reintroducing the old per-frame mesh duplication approach.

## Good contribution examples

- improve topology detection
- add cache compression
- add Blender UI controls
- add benchmark scripts
- improve manifest output

## Research note

The project already has a strong signal that stable topology exists for almost all major vehicle meshes. Keep that assumption explicit in any new code.
