BLENDER IMPACT DEBRIS WORK - TASK & WHAT WAS DONE
==================================================

WHAT THE USER ASKED
-------------------
Add realistic impact debris (shards/sparks) to the imported BeamNG crash scene
in Blender, spawned at the exact moments the car hits the ground, using the
telemetry data in beamng_impact_data.npz.

KEY CONVERSION FACTOR
---------------------
Blender frame = cache_frame * 2.5 + 400
(cache runs at 24 fps, display at 60 fps, animation starts at frame 400)

IMPORTANT BEHAVIOR NOTES
------------------------
- NPZ telemetry (x,y,z) is in world space and is used directly as Blender world coords.
- Debris materials used: paint_white, glass, plastic, steel_dark, rubber_steel.
- Each emitter is a flat 0.8 m single-face grid at z=0.15, rendered as OBJECT
  instances of the shard_* meshes, colliding with the DebrisColliders collection,
  with hide_render=True.
- Scene gravity is (0,0,-9.81), particle effector_weights.gravity = 1.0.
- Ground collision settings: use=True, use_culling=True, thickness_inner=0.02,
  thickness_outer=0.01, damping=0.1, stickiness=0.5, friction_factor=0.3.

WHAT I DID
----------
1. DETECTION
   - beamng_impact_events.py detected 43 ground-strike events from the NPZ data
     and wrote them to beamng_impact_events.json.

2. EMITTER GENERATION
   - beamng_make_emitters.py turned those 43 events into 13 emitter clusters
     and wrote them to beamng_emitters.json.

3. BLENDER BUILD
   - Created ground_debris_plane (COLLISION, member of DebrisColliders).
   - Created the Debris_* materials (paint_white, glass, plastic, steel_dark, rubber_steel).
   - Created the shard_* instance meshes.
   - Created 13 debris_emit_* emitters (particle counts from 49 up to 681).

4. BUG FIX - GRAVITY NOT APPLYING
   - Scene.use_gravity was False on the main scene, so debris hovered in air.
   - Set use_gravity = True -> fresh baked particles fall correctly.

5. BUG FIX - CORRUPTED PARTICLE BAKES
   - Re-baking while the BeamNG frame_change_pre handler
     (runtime.frame_handler._on_frame_change) was registered produced cache data
     misaligned by ~300 frames.
   - Fixed by freeing + re-baking with all frame handlers cleared, then re-registering
     the handler. Bakes are now clean.

6. FINAL BAKE & VERIFICATION
   - Re-baked all 13 emitters with gravity on, no corruption.
   - Verified: 2375 total particles arc up to ~1.6 m, all settle at z=0 by ~frame 2220,
     no tunneling (e.g. debris_emit_paint_white_2025_451_48: z=0.15 at frame 2025,
     z=1.76 at 2040, z=0.00 by 2120+).
