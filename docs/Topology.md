# Topology

## What must stay the same for cacheable objects

- vertex count
- edge count
- face count
- polygon connectivity
- edge connectivity
- stable vertex ordering

## What was already checked

- 96 of 97 objects were topology-stable
- only `flanje_e180_tierod_F` changed counts
- vertex order looks stable for the rest

## Practical conclusion

Most of the car is suitable for cache-based import.
